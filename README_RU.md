# Croco Bot

Telegram-бот для групповой игры в рисование на Node.js. Один игрок задает секретное слово, другой рисует его в canvas внутри Telegram Mini App, а бот обновляет изображение в группе, пока кто-нибудь не угадает слово.

Английская документация доступна в [README.md](README.md).

## Настройка Telegram

1. Создайте бота через BotFather и сохраните токен.
2. В BotFather откройте `/setprivacy` и выберите `Disable`.
   Иначе бот не сможет читать обычные сообщения в группе. Игроки все равно смогут угадывать через `/guess слово`.
3. Добавьте бота в Telegram-группу.
4. Игроки, которые создают слово или рисуют, должны открыть личный чат с ботом. Если бот еще не может написать игроку, в группе появится ссылка `Start`.

Важно: inline-кнопки `web_app` доступны только в личных чатах. Игра остается в группе, но форма слова и canvas для рисования открываются в личном чате с ботом с проверкой Telegram `initData`.

## Установка

```bash
npm install
cp config.example.json config.local.json
```

Отредактируйте `config.local.json`:

```json
{
  "telegramBotToken": "123456:ABCDEF",
  "publicBaseUrl": "https://your-ngrok-domain.ngrok-free.app",
  "http": {
    "port": 3000
  },
  "database": {
    "path": "./data/croco.sqlite"
  },
  "defaultLanguage": "ru",
  "imageUpdateIntervalMs": 2000,
  "gameMaxDurationMinutes": 20,
  "snapshotMaxBytes": 1500000
}
```

`config.local.json` игнорируется git.

## Локальный запуск через ngrok

Терминал 1:

```bash
ngrok http 3000
```

Скопируйте HTTPS-адрес, который покажет ngrok, например:

```text
https://abc-123.ngrok-free.app
```

Вставьте этот адрес в `publicBaseUrl` в `config.local.json`.

Терминал 2:

```bash
npm run dev
```

Бот использует Telegram polling для сообщений группы. ngrok нужен только для HTTPS-доступа к страницам Mini App и canvas.

На бесплатном аккаунте ngrok адрес часто меняется. Если адрес изменился, обновите `publicBaseUrl` и перезапустите `npm run dev`.

## Языки

Бот поддерживает русский, английский и французский через i18n. Язык по умолчанию - русский.

Язык хранится в SQLite:

- для каждого пользователя: личный чат с ботом, кнопки Mini App, форма секретного слова и canvas;
- для каждой группы: публичные сообщения, потому что Telegram отправляет одно общее сообщение для всей группы.

Когда бот впервые видит пользователя, он использует Telegram `language_code`, если язык поддерживается. После этого `/lang ru`, `/lang en` или `/lang fr` сохраняет личный выбор пользователя. Если команда отправлена в группе, она также меняет язык группы.

## Команды

```text
/newgame       начать игру в группе
/stopgame      остановить активную игру
/guess слово   предложить ответ, полезно если Privacy Mode включен
/lang ru       сохранить русский язык
/lang en       сохранить английский язык
/lang fr       сохранить французский язык
/help          показать помощь
```

## Ход игры

1. Игрок отправляет `/newgame` в группе.
2. Бот отправляет этому игроку личную Mini App для ввода секретного слова.
3. Когда слово сохранено, бот спрашивает в группе, кто хочет рисовать.
4. Первый игрок, который нажмет кнопку рисования, становится художником.
5. Бот отправляет художнику canvas в личный чат. Секретное слово показывается сверху canvas только художнику.
6. Canvas отправляет снимки на сервер; бот публикует и затем редактирует изображение в группе.
7. Первый подходящий ответ в группе выигрывает. Если бот не видит обычные сообщения группы, используйте `/guess слово`.

Ответы сравниваются без учета регистра, акцентов и пунктуации: `КАФЕ!!!` совпадает с `кафе`. Автор слова и художник не могут выиграть раунд.

## Тесты

```bash
npm test
```

Тесты покрывают нормализацию слов, i18n, пользовательские языковые настройки, проверку конфига, проверку Telegram `initData` и переходы игры в SQLite.
